# GameServer CLI
A simple command-line tool to make and manage game servers through docker.

## Get started
Following these steps will build the project and save it to your PATH.

1. Install the [.Net 10 SDK](https://dotnet.microsoft.com/en-us/download)

2. Install and run [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/)

3. Clone the repo
   ```bash
   git clone https://github.com/MatsM16/game-server
   ```

4. Run `install.ps1` or `install.sh` depending on your os.
   This will build the tool for your os and add it to path.
